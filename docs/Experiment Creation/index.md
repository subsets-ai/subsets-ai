# Experiment Creation

This section contains instructions on how to set up experiments with different customer engagement platforms (CEPs) and email service providers (ESPs).

Subsets handles the complexity of linking an experiment to an audience of users and the corresponding campaign in your CEP/ESP. The guides below walk you through the platform-specific steps for creating an experiment and connecting it to a campaign.
